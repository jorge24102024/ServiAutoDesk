# ServiAutoDesk - Sistema Modular de Gestión de Taller y Órdenes de Trabajo

## Descripción del Proyecto
**ServiAutoDesk** es una aplicación modular desarrollada en Java que simula y automatiza el funcionamiento integral de un taller mecánico automotriz. El sistema permite gestionar de manera eficiente el registro de clientes y vehículos (tanto autos como motos), la creación y seguimiento de órdenes de reparación, la aplicación de mantenimientos preventivos y correctivos, y el control de facturación y entrega final.

El proyecto está diseñado bajo los principios de la POO , aplicando herencia, polimorfismo, encapsulamiento y el uso de interfaces para garantizar un código limpio, escalable y mantenible.
